FAQ

Sering Ditanyakan

Bagaimana cara memesan template?

Pilih template yang disuka, klik Beli via WhatsApp, dan admin akan mengirimkan kode token untuk template itu. Masukkan tokennya di tab “Kelola Tamu” untuk mengelola daftar tamu.

Apa itu token?

Token adalah kode unik untuk satu undangan. Satu token terikat ke satu template dan menyimpan semua data undangan kalian — jadi link undangannya tetap sama setiap kali data diperbarui.

Berapa kali saya bisa mengubah data?

Sesuai jatah revisi token kalian — sisanya selalu tampil di editor. Melihat preview tidak mengurangi jatah; jatah hanya berkurang saat menekan Simpan.

Bisakah tamu menerima link dengan namanya sendiri?

Bisa. Tulis daftar nama tamu di editor, dan tiap nama otomatis menjadi link personal yang menampilkan nama tamu itu di sampul undangan — siap disalin atau dikirim via WhatsApp.

Bisakah undangan dipasang di domain sendiri?

Bisa. Dari editor, unduh file undangan mandiri (satu file HTML berisi semua data) lalu hosting gratis di Netlify Drop atau Cloudflare Pages — panduan langkahnya ada di editor.

File Undangan Mandiri — Untuk Domain Sendiri

Satu file HTML berisi semua data kalian — nama, acara, foto, rekening, dan musik. Buka langsung di browser, atau hosting di domain sendiri.

Hosting gratis, tanpa daftar ribet — pilih salah satu:

Netlify DropSeret file ke app.netlify.com/drop — langsung dapat alamat sendiri.
Cloudflare PagesUpload file di dash.cloudflare.com → Pages.
Hosting / cPanel sendiriUpload ke folder public_html, ganti nama jadi index.html.
  1. Unduh file-nya dengan tombol di atas.
  2. Buka salah satu layanan di atas, lalu seret & letakkan file .html-nya.
  3. Salin alamat hasil hosting — itulah link untuk tamu.
  4. Ganti data? Edit di sini, Simpan, unduh ulang, lalu upload menggantikan file lama.
