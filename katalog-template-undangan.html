Editor Undangan

Acara & Tempat

Tambahkan acara satu per satu — misalnya Akad Nikah dan Resepsi di tempat atau hari yang berbeda.

Rangkaian Acara

Susun urutan kegiatan di hari acara sesuai keinginan kalian — misalnya persiapan, akad, foto bersama, sampai resepsi. Atur urutannya dengan tombol naik / turun, dan isi lokasi tiap kegiatan kalau tempatnya berbeda-beda.

Kisah Cinta

Ceritakan perjalanan kalian bab demi bab — awal bertemu, jadian, lamaran, dan seterusnya. Kalau belum mau diisi, biarkan satu bab ini kosong saja. Atur urutan bab dengan tombol naik / turun.

Pratinjau Undangan

File Undangan Mandiri — Untuk Domain Sendiri

Unduh satu file HTML yang sudah berisi seluruh data kalian — nama mempelai, semua acara, rangkaian acara, kisah cinta, foto galeri, dan semua rekening amplop digital. File ini berdiri sendiri: buka langsung di browser, atau hosting di domain kalian sendiri supaya alamat yang dilihat tamu adalah domain kalian.

Hosting gratis, tanpa daftar ribet — pilih salah satu:

Netlify DropSeret file .html ke app.netlify.com/drop — langsung dapat alamat sendiri, bisa ganti nama & pasang domain pribadi.
Cloudflare PagesUpload file di dash.cloudflare.com → Pages — gratis, cepat, dan bisa pakai domain sendiri.
Hosting / cPanel sendiriUpload file ini ke folder public_html, lalu ganti namanya jadi index.html.
  1. Unduh file-nya dengan tombol di atas (setiap Simpan, file selalu berisi data terbaru).
  2. Buka salah satu layanan di atas, lalu seret & letakkan (drag & drop) file .html-nya.
  3. Salin alamat hasil hosting — itulah link yang dibagikan ke tamu. Tidak perlu token lagi, karena data sudah tertanam di dalam file.
  4. Mau ganti data? Edit lagi di sini, tekan Simpan, unduh file baru, lalu upload ulang menggantikan file lama.
